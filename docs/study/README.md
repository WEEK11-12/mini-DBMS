## 현재 위치

SELECT 예제로 입력 → 파싱 → 스키마 확인 → 실행 방법 선택 → 실행이라는 개념 흐름을 살펴봤습니다. B+ 트리는 빠른 검색 방법이라는 수준에서만 언급했습니다. 마지막으로 테이블 스캔이 더 읽을 행이 없음을 어떻게 알리는지 다뤘습니다.

다음 학습은 Phase 1의 파싱 상세와 INSERT 처리부터 이어갑니다. 아래 문장의 구조를 나누는 질문은 아직 답변하지 않았으므로 학습 완료로 기록하지 않았습니다.

```sql
INSERT INTO users (name) VALUES ('Kim');
```

기존 ChatGPT 대화는 사용자 질문 일부만 확인했고 GPT 답변 본문은 확인하지 못했습니다. 확인하지 못한 배경 지식을 공부한 것으로 채워 넣지 않습니다.
